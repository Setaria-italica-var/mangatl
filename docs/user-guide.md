# mangatl 使用说明

适用于 v0.3.0，Windows 10/11 x64。

## 1. 这是什么

mangatl 把日文/英文漫画页面翻译成中文，并在本机完成：

```
检测文字 → OCR → 翻译 → 擦除原文 → 按原样式排版
```

翻译可以调用云端 OpenAI 兼容接口，也可以接本地 Ollama / LM Studio / llama.cpp。
除翻译请求外，图片和文本不会离开本机。

> 这是 MVP 版本：流程可用，但复杂页面、手绘拟声词和特殊字体仍可能需要手工校对。

## 2. 安装与启动

### 便携版

1. 下载 `mangatl-portable-v0.3.0.7z`
2. 解压到有写入权限的目录，例如 `D:\Tools\MangaTL`
3. 双击 `启动.bat`

启动脚本会先检查 `runtime\` 和依赖，再打开编辑器。失败时运行 `诊断.bat`，
把生成的 `诊断结果.txt` 一起反馈。

### 从源码

仓库不包含 `runtime\` 和模型。先下载便携版，把 `runtime\`、`data\models\` 复制到
仓库根目录，然后：

```bat
setup.bat
启动.bat
```

`setup.bat` 需要系统 Python 3.12，用来更新 `runtime\` 里的依赖；之后不再依赖系统 Python。

## 3. 第一次配置

点右侧图标栏最下方的齿轮，或按 `Ctrl+,`。

### 翻译

| 预设 | 地址 | 说明 |
|---|---|---|
| DeepSeek 云端 | `https://api.deepseek.com/v1` | 填 API Key |
| Ollama 本地 | `http://127.0.0.1:11434/v1` | 需先启动 Ollama 并拉模型 |
| LM Studio 本地 | `http://127.0.0.1:1234/v1` | 需在 LM Studio 开启本地服务 |
| llama.cpp 本地 | `http://127.0.0.1:8080/v1` | 需自己启动 server |
| 回显原文 | 无 | 不翻译，返回原文，适合验证流程 |
| 自定义 | 任意 | 任意 OpenAI 兼容端点 |

- API Key 只在内存中使用；勾选「记住 Key」后用 Windows DPAPI 加密到
  `data\secrets.bin`，仅当前 Windows 用户能解
- 云端预设没填 Key 时，保存会自动切换为「回显原文」，不会阻止其他设置保存

### 后台任务

局部重绘、重识别、翻译、重检测都在后台子进程执行：

- **空闲退出**：默认 10 分钟没有任务，子进程自动退出，释放内存；下次任务会重新启动
- **软取消**：勾选后，取消会等当前一笔完成再丢弃结果；不勾选则直接终止子进程

### 启动与预览

「启动时开启实时预览」默认开启。编辑块后会自动重绘本页；不需要可以关闭。

## 4. 打开漫画

「打开文件夹」选择图片目录。支持：

```
.png  .jpg  .jpeg  .webp  .bmp
```

只扫描当前目录，不递归子目录；按文件名排序。不支持 CBZ、PDF、EPUB。

打开后会在漫画目录生成：

```
project.json     页面、文本块、阶段状态
inpainted/       擦除后的页面
result/          排版结果
```

## 5. 运行

右侧「运行」模块：

- **运行当前页**：只处理当前页，结果回到编辑器
- **开始批量**：按页码范围处理
  - 页码范围：起止页，或勾选「全部」
  - 阶段：检测 / OCR / 翻译 / 擦除 / 排版，可只勾选需要的
  - 跳过已完成：断点续跑，默认开启
  - 强制重跑：忽略完成标记
  - 卡住阈值：子进程多久没有进展就提示，默认 60 秒；可「终止进程」或「继续等待」
- **停止**：终止当前批量
- **重试失败**：只重跑失败页
- **导出日志**：把本次批量日志保存到文件

批量在独立子进程里跑，界面不会冻结，可以继续翻页和校对已完成页面。

## 6. 三种视图

| 视图 | 快捷键 | 用途 |
|---|---|---|
| 原图 | `Ctrl+1` | 看原图、选中文本块、框选块 |
| 擦除后 | `Ctrl+2` | 看 `inpainted/`，红色表示已擦除像素；可拉区域、用画笔 |
| 排版结果 | `Ctrl+3` | 看 `result/`，可拖动文字框微调位置 |

- 三种视图缩放/平移一致，切换不跳
- 原图 ↔ 擦除后保留区域选区；排版结果视图只选块
- 没有生成过的视图会提示并退回原图
- 结果图比 `project.json` 旧时，打开结果视图会提示“结果图可能过期”

## 7. 编辑文本块

在原图或结果视图点一个框，右侧「编辑」面板显示：

- 原文、译文
- 角色：`dialogue` / `sfx` / `symbol` / `texture`
- 样式：字体、字号、粗体、斜体、对齐、行距、前景色、描边色

**改动会自动应用**：停止输入约 300ms 后保存 `project.json` 并重绘当前页，
不需要点“应用”按钮。自动重绘不会强制把你切到结果视图。

其他按钮：

- 重新识别：只对当前块做 OCR
- 翻译：只翻译当前块
- 排版本页：强制重新渲染当前页
- 删除：删除当前块
- 区域操作：重新检测选区、擦除选区、添加文本块

## 8. 区域操作

在原图或擦除视图用套索/矩形框选，浮动条会出现：

| 操作 | 作用 |
|---|---|
| 重新检测 | 只在这个区域重新找文本框 |
| 局部重绘 | 用整个选区做填充，不依赖 OCR 掩膜；适合漏检的字 |
| 添加文本块 | 用选区 bbox 新建块，默认 `dialogue` |
| 取消 | 清除选区 |

局部重绘在后台执行，弹出进度窗，可取消；完成后自动切到擦除视图并刷新结果。

## 9. 擦除画笔

进入「擦除后」时，左上角出现悬浮工具条：

- 点最左侧橡皮图标，或按 `B`，进入画笔；点套索/矩形会自动退出画笔
- **左键拖动**：擦除，红色笔迹预览
- **右键拖动**：恢复，青色笔迹预览，把原图像素贴回笔迹区域
- 大小：4–200px
- 引擎：**快速**（masked）或**精细**（当前底部擦除引擎，通常 LaMa）
- 一笔提交后在工具条内显示进度和「取消」
- 最右侧「—」最小化；短按展开图标还原，按住拖动仍可移动

注意：

- 画笔只改当前页 `inpainted/`，不会改动原文
- 右键恢复只恢复笔迹覆盖的区域，来源是原始页面图，不是整页重置
- 画面外的笔迹会被忽略
- 切走擦除视图或切页时工具条隐藏；位置不保存，重启回到左上角

## 10. 搜索

`Ctrl+G` 打开跨页搜索，可在所有页的原文/译文中查找并跳转到对应块。

## 11. 输出、备份与升级

- 结果图在漫画目录 `result\`，文件名与页面相同
- 备份：`project.json`、`inpainted\`、`result\`；配置备份 `data\settings.json`，
  记住的 Key 在 `data\secrets.bin`
- 升级便携版：解压新版，覆盖 `runtime\`、`启动.bat`，保留 `data\` 和漫画项目目录
- 模型在 `data\models\`，体积较大，不必备份，可重新下载

## 12. 常见问题

**启动提示缺少 runtime?**  
运行 `setup.bat`，或重新解压完整便携包。

**翻译失败 / 没有 Key?**  
设置里选「回显原文」先验证流程，或填云端 Key、启动本地模型。

**LaMa 第一次很慢?**  
首次加载约 15–35 秒，属正常；之后同一后台进程会复用。

**页面很卡?**  
大尺寸页面（长条漫）重排较慢；可先只跑检测/OCR，校对后再单独排版。

**结果图过期?**  
项目文件比结果图新；点「运行本页」或「排版本页」重新生成。

**杀毒软件误报?**  
便携版未签名，可能被误报；用 `SHA256SUMS.txt` 校验压缩包后再决定是否信任。

**中文路径/长路径?**  
支持中文路径；极长路径建议把项目移到更浅的目录。

## 13. 隐私与许可

- 不记录漫画原文/译文到日志；异常日志只含栈和版本信息
- 不上传图片到自制服务器；只请求你配置的翻译端点
- 项目以 GPL-3.0 发布；第三方组件与模型许可见 `NOTICE`
- 机翻结果仅供个人阅读；公开分享请标注「机翻」
