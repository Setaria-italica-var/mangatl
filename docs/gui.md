# 桌面编辑器（MVP）

## 启动

```bat
.venv\Scripts\activate.bat
uv pip install "mangatl[gui]"        # 一次即可，装 PySide6
python -m mangatl gui samples\vol1
```

## 界面布局

```
┌──────────┬────────────────────────────┬──────────────────┐
│ 页面列表 │  画布（缩放/平移/框选）      │ 文本块检查器      │
│ 001.jpg  │                            │ 原文 / 译文       │
│ 002.jpg  │   蓝=对白 橙=拟声词         │ 角色下拉          │
│ ...      │   灰=符号 深灰=花纹          │ [应用][重识别]    │
│          │                            │ [翻译][重排版]    │
│          │                            │ ── 区域操作 ──    │
│          │                            │ [重检测][重擦除]  │
│          │                            │ [添加文本块]      │
└──────────┴────────────────────────────┴──────────────────┘
```

## 右侧模块栏

| 图标 | 模块 | 内容 |
|---|---|---|
| ✎ | 编辑 | 块文本/译文/角色、应用、重识别、翻译、排版、删除；区域重检测/擦除/添加 |
| ▦ | 文本块 | 当前页块表格，可直接改原文/译文，双击跳转画布 |
| ⌕ | 搜索 | 跨页搜索，支持低分/空译文/待校对/仅气泡内过滤 |
| ▶ | 运行 | 阶段勾选、运行当前页/全部页、日志 |
| ⚙ | 设置 | 强调色（蓝/紫/绿/橙）与环境状态 |

## 块样式面板（C1）

选中块后，右侧「编辑」面板提供：

| 控件 | 说明 |
|---|---|
| 字体 | 黑体 / 宋体 / 手写（映射到 sans / serif / hand 字体族） |
| 字号 | 0 = 自动（按气泡适配），非 0 作为起始字号 |
| 粗体 / 斜体 | 粗体可用；斜体当前仅记录，渲染暂未倾斜（字体限制） |
| 对齐 | 居中 / 左 / 右 |
| 行距 | 0 = 自动（1.15），可调 0–3 |
| 前景色 / 描边色 | 取色对话框，不选则自动从原图估计 |
| 应用样式并排版 | 写入块样式并立即重绘本页 |

样式保存在 `project.json` 的 `blocks[].style`，为空表示全自动。

## 底部细条（参考 BT BottomBar）

| 控件 | 作用 |
|---|---|
| 检测 / OCR / 擦除 / 翻译 下拉框 | 运行时使用的引擎，与 CLI 参数等价 |
| 图层透明度滑块 | 调整文本框叠加层透明度，便于看原图 |

BT 的底部栏是固定高度细条（模块选择器 + 两个透明度滑块 + 三个模式开关）；
我们采用同样的形态，但把"模块切换"移到了右侧图标栏，避免占用画布高度。

## 导航（A1/A2/A3/A4/A5）

| 功能 | 说明 |
|---|---|
| 左侧缩略图列表 | 图片缩略图 + 状态点，右键：运行本页/重置本页/打开结果图/重命名 |
| 底部模块页签 | 编辑/文本块/搜索/运行/设置，可用 `＋` 添加；与页面无关 |
| 全局搜索 `Ctrl+G` | 跨页搜原文/译文，可按「低分 / 空译文 / 待校对 / 仅气泡内」过滤，双击跳转 |
| 旋转 90° `R` | 只旋转视图，不改文件；再次按继续旋转 |
| 页面状态点 | `○` 未处理 `◐` 部分完成 `●` 全部完成 `!` 有待校对块 |

## 工具

| 工具 | 快捷键/操作 | 说明 |
|---|---|---|
| 选择 | 默认 | 点块选中；拖拽平移画布 |
| 套索 | 工具栏「套索」 | 按住左键画任意闭合区域，松开生效 |
| 矩形 | 工具栏「矩形」 | 拖出矩形区域 |
| 缩放 | 滚轮 | 以鼠标为中心缩放 |
| 平移 | 中键拖动 | 任意时刻可用 |
| 适应窗口 | `F` | |
| 上/下一页 | `PgUp` / `PgDn` | |
| 撤销 | `Ctrl+Z` | 恢复最近一次块编辑（保留 50 步） |
| 保存 | `Ctrl+S` | 写回 `project.json` |

## 区域操作（对应"手工修补"）

先套索/矩形选中区域，再点右侧按钮：

| 按钮 | 行为 |
|---|---|
| **区域重新检测** | 裁出该区域 → 跑 CTD → 坐标映射回整页 → 新增文本块 |
| **区域重新擦除** | 用检测器文字掩膜 ∩ 区域做擦除，**不会抹到画面** |
| **区域添加文本块** | 以选区 bbox 新建块，输入原文/译文后「应用文本」 |

## 文本块操作

| 按钮 | 行为 |
|---|---|
| 应用文本 | 写回原文/译文/角色，重算角色与 `project.json` |
| 重新识别 | 对该块单独跑 manga-ocr，结果填入原文框 |
| 翻译此块 | 用配置的 OpenAI 兼容端点翻译该块（需 `MANGATL_API_KEY`） |
| 重新排版 | 用当前块重绘 `result/<page>`（字号自适应、竖排跟随原文） |
| 删除选中块 | 删除并重排序号 |
| 打开结果图 | 用系统看图器打开排版结果 |

## 与流水线的关系

编辑器**不会**自动跑整条流水线；它直接操作 `project.json` 和 `inpainted/`、`result/`：

- 想先自动处理，再手工修：先跑 `python -m mangatl run ...`，再开 GUI
- 修正后继续用 CLI 跑后续阶段也没问题，阶段完成位会一起更新

## 当前限制（MVP）

- 没有图层/蒙版编辑，套索只用于区域操作
- 撤销只覆盖块列表，不撤销文件写入（重跑流水线可重生成）
- 画布暂不支持旋转/翻转
- 字体依赖系统中文（Windows 自带微软雅黑即可）
