## 2. 现状差距（优先级）

1. **块属性面板（C1）**：没有字体/字号/颜色控制，排版只能全自动
2. **块拖拽缩放（B2）**：框错了只能删了重画
3. **画笔/橡皮蒙版（B4/B5）**：局部修补能力不足
4. **块表格视图（E1）**：无法快速定位问题块
5. **运行面板（D1）**：每次改参数要回命令行
6. **页面底部栏（A2）**：翻页效率低（见 §3）

## 3. Excel 式底部页签（A2 改进方案）

```
┌────────────────────────────────────────────────────────────┐
│                   画布（当前页）                            │
├────────────────────────────────────────────────────────────┤
│ ◀ ▶ │ 001 ● │ 002 ● │ 003 ○ │ 004 ◐ │ ... │ ＋ │ 搜索框  │
└────────────────────────────────────────────────────────────┘
```

- 每个页签显示页码 + 状态点：`○` 未处理、`◐` 部分完成、`●` 已完成、`!` 需校对
- 双击页签重命名；右键菜单：运行本页 / 重置本页 / 打开结果图 / 删除页
- 拖拽排序；`＋` 添加图片；右侧搜索框过滤页签
- 与左侧页面列表二选一（默认底部页签，可切换）
