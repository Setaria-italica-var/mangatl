================================================================
  MangaTL 便携版 使用说明
  版本：v0.3（2026-10）
================================================================

一、这是什么
----------------------------------------------------------------
一个把日文/英文漫画一键翻成中文的桌面工具。
流程：识别文字 → 翻译（用你自己的 API Key）→ 擦掉原文 → 按原样式排版（支持竖排）。
除翻译需要联网外，其余全部在本机完成。

二、解压与启动
----------------------------------------------------------------
1. 把压缩包解压到任意「有写入权限」的目录，例如：
      <非系统盘>\Tools\MangaTL
      U 盘根目录\MangaTL
   不要放在：
      C:\Program Files\...      （需要管理员权限，无法写入配置）
      C:\ 根目录                （部分系统限制写入）
      只读的光盘/U 盘
2. 双击 MangaTL.exe。
3. 首次运行若弹出「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。
   （本程序未购买代码签名证书，属正常提示。）
4. 启动约 1–3 秒出现主界面；引擎在后台预热模型，不影响操作。

三、目录说明（不要随意改结构）
----------------------------------------------------------------
  MangaTL.exe        主程序，双击它
  _internal\         运行库（Qt、PyTorch 等），请勿修改或删除
  data\              配置、模型、字体、日志（**升级时要保留**）
  projects\          默认项目目录（每本漫画一个子目录）
  source\            本程序的完整源代码（GPL 许可要求）
  LICENSE  NOTICE    许可证与第三方声明
  使用说明.txt       本文件

四、第一次使用
----------------------------------------------------------------
1. 模型
   - 完整版（full）已内置模型，直接可用。
   - 精简版（lite）首次启动会提示下载；也可离线安装：
     把模型包解压后，保证 data\models\ 下直接看到 ctd\、ocr\、inpaint\ 等目录。
2. 翻译设置（必须做）
   设置 → 翻译 → 新建配置：
     名称：随便起（如 deepseek）
     接口地址：https://api.deepseek.com/v1      （填到 /v1 为止）
     模型：deepseek-chat
     API Key：粘贴你的 Key
   点「测试连接」，成功即可。
   支持任何 OpenAI 兼容接口：OpenAI、DeepSeek、OpenRouter、Ollama、vLLM 等。
3. 语言
   设置 → 翻译 → 源语言选「日文」或「英文」，目标语言选「简体中文」。
   竖排：「跟随原文」为默认（日文竖排 → 中文竖排）；
        想统一横排就改成「总是横排」。

五、日常使用
----------------------------------------------------------------
1. 打开：主界面「打开文件夹」或「打开 CBZ」，也可以直接把文件夹/CBZ 拖进窗口。
2. 运行：点「开始」。单页大约 6–10 秒（8GB 显存的 N 卡），一本 180 页约 20–30 分钟。
3. 校对（建议）：
      A / D            上一页 / 下一页
      Tab              跳到下一个文本框
      Enter            编辑译文
      Ctrl + Enter     重渲染当前页
      空格             临时查看原图
      Ctrl + Z / Y     撤销 / 重做
   标黄的是低置信度或排版放不下的块，优先看这些。
4. 导出：「导出」→ 选 CBZ 或文件夹，输出到 projects\<书名>\result\。

六、常见问题
----------------------------------------------------------------
Q1 提示「目录不可写」，无法保存配置？
   程序被放在受限目录。请整个文件夹移动到 D 盘或用户目录下再运行。

Q2 提示显存不足，或速度很慢？
   设置 → 硬件 → 档位：8GB 用「高（1024）」，4–6GB 用「中（768）」，紧张时用「低（512）」。
   同时关闭浏览器里占用显存的页面、其他 AI 工具。

Q3 模型下载失败？
   设置 → 模型 → 换镜像后重试；或按第四节用离线模型包。

Q4 杀毒软件报毒？
   未签名的 exe 常被误报。可用压缩包附带的 .sha256 校验文件完整性；
   确认无误后把程序目录加入信任列表。

Q5 换了台电脑，API Key 失效？
   默认不保存 Key，换机需重新填写（这是安全设计，不是 bug）。
   如果经常换机：设置 → 翻译 → 勾选「用主密码加密保存」，之后输入一次主密码即可。

Q6 中文路径、很深的目录能用吗？
   可以；但如果路径特别长（超过约 240 字符），建议把项目移到更浅的目录。

Q7 想换字体？
   把 .ttf / .otf 放进 data\fonts\，重启后在「设置 → 字体」里选择。
   内置：思源黑体、思源宋体、霞鹜文楷。

Q8 只想重跑某一页 / 某一阶段？
   校对页右键该页 →「重跑此页」或「从此页起重跑」；也可在「运行」页勾选阶段。

Q9 拟声词（SFX）被擦掉了？
   默认策略是「保留不擦」。若被误擦，设置 → 排版 → SFX 策略改为「保留」后重跑该页。

Q10 竖排排版出现标点跑到行首？
   请把该页截图与 data\logs\engine.log 一起反馈（这是已知需要持续调优的点）。

七、升级与备份
----------------------------------------------------------------
升级：解压新版，覆盖 MangaTL.exe 和 _internal\，**保留 data\ 与 projects\**；
      或解压到新目录，把旧的 data\、projects\ 拷贝过去。
备份：data\config.json + data\secrets.enc + projects\ 三样即可。
      模型（data\models\）体积大，不必备份，可重新下载。

八、日志与反馈
----------------------------------------------------------------
日志在 data\logs\：
  app.log      界面与操作
  engine.log   识别/翻译/修复/渲染
默认不记录原文与译文内容，也不记录 API Key。
反馈问题时附上 engine.log 与出问题的页面截图。
