# mangatl v0.3.0

本地漫画翻译桌面工具：检测 → OCR → 翻译 → 擦除 → 中文排版，主要面向日文竖排漫画（也支持英文）。
全部推理在本机运行，只有云端翻译会按需使用 API Key。

## 下载

| 文件 | 说明 |
|---|---|
| `mangatl-portable-v0.3.0.7z` | 便携版（约 1.86 GB） |
| `SHA256SUMS.txt` | SHA256 校验 |

> 原始目录约 3.5 GB，7-Zip 压缩后 1.86 GB，低于 GitHub 单个附件 2 GB 上限，因此不再分卷。
> 如果以后压缩后超过 2 GB，用 `tools/pack_release.ps1 -VolumeMB 900` 重新生成分卷。

## 安装 / 启动

1. 安装 [7-Zip](https://www.7-zip.org/)（已安装可跳过）
2. 下载 `mangatl-portable-v0.3.0.7z`
3. 右键该文件 → 7-Zip → **解压到当前文件夹**
4. 进入解压出的 `mangatl-portable`，双击 **`启动.bat`**
5. 首次启动可用 `诊断.bat` 检查运行环境

要求：Windows 10/11 64 位。便携版已内置 Python 运行时和模型，不需要单独安装 Python。

## 校验

```powershell
Get-FileHash .\mangatl-portable-v0.3.0.7z -Algorithm SHA256
```

把输出与 `SHA256SUMS.txt` 对照，大小写不敏感。

## 本版内容

- 检测 → OCR → 翻译 → 擦除 → 排版完整流水线，内置漫画 OCR 与 LaMa 擦除
- 便携运行时：Python 与依赖在 `runtime/` 内，`启动.bat` 一键启动
- 局部区域：重新检测、重新识别、翻译所选、局部重绘，全部后台执行，不卡界面
- 擦除视图悬浮工具条：左键擦除、右键恢复原图；可调笔刷大小、快速/精细引擎、内联进度与取消
- 编辑面板实时应用：原文/译文/角色/字体/字号/颜色改动后自动保存并重绘，无需「应用」按钮
- 设置弹窗：翻译预设、本地模型、DPAPI Key 存储、后台任务空闲退出/软取消
- 后台任务子进程：NDJSON 通信、进度与取消、空闲自动退出
- 界面：侧栏自适应滚动、窗口最小化/关闭按钮、全屏、暗色主题
- 批量任务：进度窗口、卡住检测、可取消

## 已知问题

- 首次使用 LaMa 擦除需加载权重，约 15–35 秒；之后复用
- 云端翻译需要 API Key；未配置时自动回显原文
- 手动擦除的“恢复”只恢复笔迹区域，来源是原始页面图
- 自动重排对超大页面可能耗时，属于正常现象
